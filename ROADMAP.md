# MADFAM - Catálogo Completo de Cursos

## Roadmap

### v1.0 (MVP)
- List all courses (GET /api/courses)
- Add new course (POST /api/courses)
- Basic UI for viewing and adding courses

### v1.1
- Update course (PUT /api/courses/:id)
- Delete course (DELETE /api/courses/:id)
- Enhanced form validation
- UI improvements (responsive design, accessibility)

### v1.2
- Search and filter courses
- Course details page
- Pagination for course listings

### v2.0
- Authentication and authorization (instructor/admin roles)
- Payment integration (Stripe)
- Course enrollment and user dashboard

### v2.1
- Ratings and reviews
- Notifications (email)

### v3.0
- Mobile app support
- Analytics and reporting

## GitHub Integration
- Create GitHub Issues for each roadmap item
- Group issues into Milestones matching version releases
- Use a GitHub Project board to track progress
- Automate project board updates with GitHub Actions
