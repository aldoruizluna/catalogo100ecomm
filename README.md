# MADFAM - Catálogo de Cursos Especializados

![MADFAM Logo](https://via.placeholder.com/150) <!-- Consider adding actual logo -->

## Descripción del Proyecto

MADFAM ofrece un catálogo completo de 100 cursos especializados en:
- Manufactura Sostenible
- Transformación Digital
- Filosofía Solarpunk

El proyecto incluye un sitio web moderno y responsive que presenta los cursos disponibles con información detallada sobre cada uno.

## Características Principales

- **Diseño Responsivo**: Adaptable a dispositivos móviles y desktop
- **Animaciones Modernas**: Efectos visuales atractivos usando Anime.js
- **Navegación Intuitiva**: Menú accesible en todas las plataformas
- **Secciones Organizadas**:
  - Acerca de MADFAM
  - Fabricación Sostenible
  - Transformación Digital
  - Filosofía Solarpunk
  - Certificaciones

## Tecnologías Utilizadas

- **Frontend**:
  - HTML5, CSS3
  - Tailwind CSS
  - JavaScript (ES6+)
  - Anime.js (para animaciones)
  - Font Awesome (iconos)
  
- **Diseño**:
  - Enfoque Mobile-First
  - Tipografía moderna (Montserrat, Poppins)

## Estructura del Proyecto

```
catalogo100ecomm/
├── css/
│   └── main.css         # Estilos personalizados
├── js/
│   ├── animations.js    # Lógica de animaciones
│   └── main.js          # Funcionalidad principal
├── index.html           # Página principal
└── README.md            # Este archivo
```

## Instalación y Ejecución

1. Clona el repositorio:
   ```bash
   git clone [URL del repositorio]
   ```

2. Abre el archivo `index.html` en tu navegador:
   ```bash
   start index.html
   ```

## Personalización

Para modificar el contenido:
1. Edita el archivo `index.html` para cambiar el texto y estructura
2. Actualiza los estilos en `css/main.css`
3. Ajusta las animaciones en `js/animations.js`
